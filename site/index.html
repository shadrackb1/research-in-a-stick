How to use

Three steps. That’s it.

If you can use a USB drive, you can use RIS.

  1. 01
    Plug in the stick

    Insert the USB drive into a Windows computer (most school and office PCs work).

  2. 02
    Double-click “launcher”

    Open the stick in File Explorer and double-click launcher.bat. A black window may flash — that’s normal.

  3. 03
    Use it in your browser

    A page opens on the computer (like 127.0.0.1:8765). Type a question. The first answer can take half a minute while everything wakes up; later answers are faster.

Tip: keep the stick plugged in while you work. Unplug the Wi‑Fi if you like — RIS still answers.

For the curious

How it works under the hood

You do not need this section to use RIS. It’s here if you want the details.

What’s inside the stick?
A small AI program that runs on the computer’s processor (no fancy graphics card required), a set of notes and wiki articles, a simple local web page for chatting, and a one-click start script. Nothing is installed permanently on the PC unless you choose to.
Does it phone home?
No. Questions and files stay on that computer and the stick. There is no account to create and no tracking built into the core app.
Which computers work?
Windows PCs with a normal amount of memory (about 4 GB or more) and a USB port. Older laptops are fine — it uses the processor, not a gaming GPU.

Questions

Common questions

Is this the same as ChatGPT?
Not quite. ChatGPT lives on the internet. RIS lives on your USB stick and answers without sending your questions to a company server.
Do I need to be good with computers?
No. If you can plug in a USB drive and double-click a file, you can use it. A friend or lab assistant can help the first time.
What if there is no internet?
That is the point. RIS is designed for offline use. Internet is only needed if you want to download bigger content packs later.
Are my files private?
Your documents stay on the stick and the computer you use. There is no account and no built-in tracking.
Which computer do I need?
A Windows laptop or desktop with a USB port. A fairly ordinary machine is enough — you do not need a gaming PC.
